# Documentación — Formulario de Incidencias (Rental Holidays)

App interna para registrar incidencias de mantenimiento de los alojamientos, adjuntar su factura y guardarla ordenada en Google Drive.

| Archivo | Para qué sirve |
|---|---|
| [contexto.md](contexto.md) | Qué es la app, cómo está montada, dónde vive cada dato, IDs. Empieza aquí. |
| [decisiones.md](decisiones.md) | Por qué está hecha así: cada decisión con su motivo y lo que se descartó. |
| [errores-y-soluciones.md](errores-y-soluciones.md) | Fallos reales que ya pasaron: síntoma, causa, arreglo y cómo detectarlos. |
| [operacion.md](operacion.md) | Cómo desplegar, verificar, tareas de cada enero y pendientes manuales. |

Para usuarios finales hay un manual dentro de la propia app (pestaña **Ayuda**).

> El `README.md` de la raíz del repo describe una arquitectura antigua (Python/Flask + cuenta de servicio) que **ya no se usa**. La app actual es React + Google Apps Script; ver [contexto.md](contexto.md#archivos-heredados).
